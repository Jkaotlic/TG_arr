# Почему качается итальянское, хотя профили качества настроены — 2026-07-30

Вопрос от Anex. Ответ получен чтением живой конфигурации Scryer и одним реальным
поиском релизов. **Конфигурацию Scryer я не менял** — ниже описано, что именно стоит
поправить и почему; решение за тобой.

## Короткий ответ

Профили качества про язык вообще ничего не говорят, а языковое правило **штрафует, но не
запрещает** — и «итальянский» под его штраф даже не попадает.

## Что настроено на самом деле

Профили (`qualityProfileSettings` + `libraries`):

| Библиотека | Фасет | Профиль |
|---|---|---|
| Movies | MOVIE | `4k` — «4K Remux + 1080P Fallback» |
| Series | SERIES | `4k` — «4K Remux + 1080P Fallback» |
| Anime | ANIME | `1080p` |

Языкового условия в профиле нет. Язык живёт в единственном наборе правил
(`ruleSets`): **«English Audio + Russian Subtitles»**, priority 100, фасеты movie+series.
Его собственное описание:

> Prefer English audio and Russian subtitles; penalise (**do not block**) releases
> without English audio.

Полный разбор его Rego:

| Правило | Условие | Вес |
|---|---|---|
| `english_audio_bonus` | среди аудио есть `eng` | **+250** |
| `russian_subtitles_bonus` | среди субтитров есть `rus` | **+250** |
| `russian_audio_without_english` | есть **русское** аудио И нет английского | **−1000** |
| `verified_file_without_english` | у проверенного файла (импорт) нет `eng` | **−1000** |

Отсюда два вывода:

1. **Итальянского в правиле нет.** Штраф −1000 требует `release_has_russian_audio`.
   Релиз с итальянским аудио и без английского не попадает ни под один пункт — он просто
   не получает бонус.
2. **Ничего не блокируется.** `allowed` по языку не выставляется в `false`. Если лучших
   кандидатов нет, Scryer возьмёт что есть.

## Что показал живой поиск (и это главное)

Один запрос релизов для «Michael 2026», 50 кандидатов:

```
score 5445  Michael.2026.2160p.UHD.Blu-ray.Remux.DV.HDR.HEVC.TrueHD.Atmos.7.1-CiNEPHiLES
            коды: quality_tier_0, source_bluray, video_codec_quality_high,
                  audio_codec_lossless, dolby_vision_bonus, hdr_bonus, prefer_remux_match,
                  atmos_preferred_match, group_gold …
                  ← НИ ОДНОГО языкового кода

score 4130  Майкл / Michael [2026, США, Великобритания … UHD BDRemux]
            коды: … english_audio_bonus, russian_subtitles_bonus   ← +500
```

Английский BluRay Remux **не получил** языкового бонуса: индексер (Knaben) не заявил
языки, поэтому `input.release.languages_audio` пуст и правило не сработало. А русская
раздача с RuTracker, где языки перечислены в описании, собрала +500.

То есть правило по факту награждает **подробно описанную раздачу**, а не английское
аудио. И именно мультиязычные раздачи с русских трекеров (те самые, что тащат
итальянские дорожки) описывают себя подробнее всех.

## Что сделано в боте

Бот об этом молчал: он не запрашивал и не показывал ничего про язык. `ParsedReleasePayload`
языкового поля не имеет, но у вердикта профиля есть `scoringLog` с кодами сработавших
правил — оттуда и берётся ответ. Карточка релиза теперь различает три случая:

- `🔊 Аудио: есть английское` — сработал `english_audio_bonus`;
- `⚠️ Аудио: английского нет — политика снизила рейтинг, но релиз не запрещён`;
- `❔ Аудио: языки не указаны в раздаче — политика не смогла их проверить`.

Третий случай отделён сознательно: сказать «нет английского» про тот самый BluRay Remux
было бы неправдой.

## Что стоит поправить в Scryer (твоя зона)

Синтаксис жёсткой блокировки в Scryer — `scryer.block_score()`; он используется в
штатных шаблонах (`rulePackTemplates`), например «Require Japanese audio (post-download)»:

```rego
score_entry["no_japanese_audio"] := scryer.block_score() if {
    input.file != null
    not has_japanese_audio
}
```

Аналог для английского, по возрастанию жёсткости:

**1. Штрафовать отсутствие английского вообще, а не только «русское без английского»:**

```rego
score_entry["audio_without_english"] := -1000 if {
    count(input.release.languages_audio) > 0
    not release_has_english
}
```

**2. Блокировать на этапе импорта — по фактическим дорожкам файла** (надёжнее всего,
потому что читаются реальные дорожки, а не описание раздачи):

```rego
score_entry["file_without_english_audio"] := scryer.block_score() if {
    input.file != null
    count(input.file.audio_languages) > 0
    not file_has_english
}
```

Цена варианта 2: торрент успеет скачаться, и только импорт будет отклонён — трафик
потратится, но в библиотеку неанглийское не попадёт.

**Чего делать не стоит:** блокировать на этапе выбора релиза по `input.release.languages_audio`.
Как показано выше, у половины хороших раздач языки не заявлены — такая блокировка отсечёт
именно английские релизы с зарубежных трекеров.

## Отдельно: почему в файле итальянская дорожка играет первой

Правило проверяет **наличие** английской дорожки, а не её порядок. Релиз вида
`DDP5.1.ENG.Atmos.ITA` содержит обе, бонус получает, а какая дорожка окажется дорожкой по
умолчанию — решает контейнер. Если Emby выбирает не ту, это настройка предпочитаемого
языка аудио в самом Emby (профиль пользователя), а не вопрос политики Scryer.
